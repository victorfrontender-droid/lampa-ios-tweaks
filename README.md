# iOS Tweaks для Lampa

Плагин для Lampa на iPhone и iPad. На других устройствах ничего не делает.

## Что делает

### Очистка «Сейчас играет»

iOS показывает видео из Lampa как обычное воспроизведение медиа: в Dynamic Island и в виджете на экране блокировки. Сама Lampa эту информацию не очищает, поэтому после закрытия приложения виджет может остаться.

1. Когда Lampa уходит в фон (свернули, открыли список приложений, заблокировали экран), плагин закрывает плеер обычным способом, с сохранением позиции просмотра
2. Полностью выгружает видео и очищает информацию «Сейчас играет»
3. При обычном закрытии плеера тоже выгружает видео и очищает «Сейчас играет»

Если включён режим «картинка в картинке», плагин ничего не трогает.

### Горизонтальный режим

Веб-страница на iPhone не может повернуть экран сама, поэтому плагин поворачивает плеер на 90° средствами CSS. Работает при включённой блокировке поворота.

1. При запуске видео во встроенном плеере, если телефон держат вертикально, плеер разворачивается горизонтально: держите телефон кнопками громкости вверх
2. В панели плеера появляется кнопка поворота: она выключает и включает горизонтальный режим, выбор запоминается
3. Касания пересчитываются под повёрнутый экран: двойное касание слева или справа перематывает, свайп по полосе времени перематывает
4. Если телефон повернуть по-настоящему (с выключенной блокировкой), плагин ничего не поворачивает

Ограничение: часы, батарея, Dynamic Island, уведомления и регулятор громкости iOS остаются вертикальными.

## Установка

1. Откройте Лампу
2. `Настройки → Расширения / Плагины → Добавить плагин`
3. Вставьте:

```text
https://cdn.jsdelivr.net/gh/victorfrontender-droid/lampa-ios-tweaks@main/ios-tweaks.js
```

4. Перезапустите Лампу

## Проверка

1. Запустите серию во встроенном плеере
2. Сверните Lampa и закройте её смахиванием
3. Заблокируйте телефон: виджета плеера быть не должно
4. Откройте серию снова: Лампа предложит продолжить с того же места

## Важно

- Плагин работает только со встроенным плеером Lampa, внешние плееры (Infuse, VLC и другие) он не трогает
- Фоновое воспроизведение звука отключается: при сворачивании Lampa плеер закрывается
- Если iOS завершил приложение, не дав странице получить событие ухода в фон, плагин не успеет сработать

## Отладка

В консоли Лампы (DevTools) логи включаются так:

```js
Lampa.Storage.set('ios_tweaks_debug', true)
```

Выключить:

```js
Lampa.Storage.set('ios_tweaks_debug', false)
```

Префикс логов: `[iOS-Tweaks]`
